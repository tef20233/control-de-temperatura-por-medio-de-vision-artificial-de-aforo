# Modelos para el sistema CLI de aforo

Coloca aquí tus modelos YOLO si quieres usar una carpeta local dedicada.

En este proyecto, por defecto el código buscará los modelos en:

- `../models/` (carpeta de modelos ya existente en el backend)

Puedes:
- Mantener los `.pt` en `backend/models` (recomendado, ya están ahí), o
- Copiarlos también a esta carpeta y ajustar la ruta con `--model` en la CLI.
